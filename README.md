# first-10-paying-users

前 10 个付费用户 playbook —— "The first ten is a conversation problem, not a marketing problem"。

## 方法

B2B 和 B2C 是两套打法。B2B 走窄切口 + 100 家精准名单 + 个性化 outreach + 一对一演示 + 创始会员价 + 爽点时刻要转介绍；B2C 走真痛点 + 早鸟版 MVP + 混进 2–3 个痛点社区 + 低摩擦创始价 + 死磕前 5 分钟体验 + 私聊每个买家。底层是 YC 创始人实证的三阶段：1–3 靠人脉，4–10 靠笨功夫，10–50 才规模化。

## 包含内容

- `SKILL.md`：B2B/B2C 判断表、三阶段总纲、六个静默杀手自查清单、使用流程
- `references/b2b-playbook.md`：B2B 七步详解（含中国渠道映射：微信、行业群、抖音/小红书私信、线下展会）
- `references/b2c-playbook.md`：B2C 七步详解（含中国社区映射：小红书、即刻、V2EX、知乎、豆瓣、B站）
- `references/churn-followup.md`：流失用户 48 小时跟进法——前 10 单里最便宜的 roadmap 输入
- `references/yc-findings.md`：YC 创始人实证的 9 条发现，每条配独立开发者的实操含义
- `references/outreach-templates.md`：中文 outreach 话术模板——B2B 私信、熟人介绍、转介绍、流失跟进、B2C 社区问题帖，开箱即用

## 用法

把本仓库作为 AI 助手的知识库，告诉它你的产品是 B2B 还是 B2C、现在 0–10 单卡在哪一步，让它按对应 playbook 给你列出本周行动清单（每天 outreach 数量、名单进度、话术）。
